# 1. Qué es este proyecto

El proyecto grupal final es la actividad de cierre del curso de Código y Programación del **Samsung Innovation Campus Chile 2026 – Cohort 2**.

Durante las próximas clases, cada equipo deberá seleccionar un dataset de datos reales, formular una pregunta de análisis concreta y desarrollar una aplicación interactiva utilizando **Streamlit o Gradio** para responder dicha pregunta mediante visualizaciones y análisis de datos.

El objetivo no es demostrar el uso de todas las herramientas vistas durante el curso, sino utilizar las herramientas adecuadas para resolver un problema con datos y comunicar los resultados de forma clara a una audiencia no técnica.

El proyecto comenzará a organizarse desde la **primera clase**, donde cada equipo deberá definir a sus integrantes y comenzar a explorar posibles datasets y temas de interés. A medida que avance el curso, irán construyendo el análisis y la aplicación hasta su presentación final.

# 3. Lo que deben entregar

## Entregable 1: Pull Request en GitHub

En la fecha indicada por el docente, el equipo deberá tener un Pull Request aprobado que incluya:

* Carpeta `/proyectos/nombre-del-equipo/` con la estructura requerida.
* Al menos un notebook `.ipynb` con el análisis documentado y comentado.
* Una aplicación funcional desarrollada con **Streamlit o Gradio**.
* `requirements.txt` actualizado.
* `README.md` con descripción, dataset, pregunta de análisis, hallazgos, enlace a la aplicación e integrantes.
* Aplicación publicada en **Streamlit Cloud, Hugging Face Spaces o una plataforma equivalente**, con la URL incluida en el `README.md`.

## Entregable 2: Presentación final

* 7 minutos de presentación con la aplicación abierta en pantalla.
* 3 minutos de preguntas del docente y del grupo.
* Todos los integrantes deben estar presentes.

## Requisitos mínimos de la aplicación

| Elemento        | Requisito mínimo                                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Visualizaciones | Al menos 3 visualizaciones relevantes para responder la pregunta de análisis.                                                                                    |
| Interactividad  | Al menos 2 controles interactivos (filtros, sliders, dropdowns, botones, entradas de texto u otros) que permitan explorar los datos o actualizar los resultados. |
| Indicadores     | Al menos 3 métricas, KPIs o indicadores resumidos visibles en la interfaz.                                                                                       |
| Explicación     | Una sección que comunique el hallazgo principal en lenguaje no técnico.                                                                                          |
| Dataset         | Datos reales con un volumen suficiente para responder la pregunta de análisis, con licencia verificable y fuente citada en el `README.md`.                       |
| Publicación     | La aplicación debe estar publicada y accesible mediante una URL pública.                                                                                         |

> **Bibliotecas de visualización sugeridas:** Plotly, Altair, Folium, Matplotlib, PyDeck u otras equivalentes, según las necesidades del proyecto.
